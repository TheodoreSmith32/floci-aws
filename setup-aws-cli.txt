SETUP: AWS CLI ON WSL UBUNTU -> CONNECT TO LOCALSTACK (FLOCCI ENV)
===================================================================

Note: assuming "flocci" refers to your LocalStack instance (the
environment you've been using throughout, endpoint on port 4566,
credentials test/test). Replace the endpoint IP/host below with your
actual one if different.


STEP 1: UPDATE PACKAGES
------------------------------------------------------------------
sudo apt update && sudo apt upgrade -y


STEP 2: INSTALL DEPENDENCIES
------------------------------------------------------------------
sudo apt install -y curl unzip


STEP 3: DOWNLOAD AWS CLI V2
------------------------------------------------------------------
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"

(If you're on WSL running on ARM, e.g. Apple Silicon host via WSL2,
use the aarch64 build instead:
curl "https://awscli.amazonaws.com/awscli-exe-linux-aarch64.zip" -o "awscliv2.zip"
)


STEP 4: UNZIP AND INSTALL
------------------------------------------------------------------
unzip awscliv2.zip
sudo ./aws/install


STEP 5: VERIFY INSTALLATION
------------------------------------------------------------------
aws --version

Expected output similar to:
aws-cli/2.x.x Python/3.x.x Linux/x.x.x exe/x86_64.ubuntu.xx

STEP 6 : CONNECT TO FLOCI-LOCAL 
--------------------------------------

export AWS_ENDPOINT_URL=http://xxxx:4566
export AWS_ACCESS_KEY_ID=test
export AWS_SECRET_ACCESS_KEY=test
export AWS_DEFAULT_REGION=us-east-1


STEP 7 : CHECK CONNECTION ON S3 
-------------------------

aws s3 ls
